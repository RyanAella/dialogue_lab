# Lab für Sozioinformatik: Gesprächstraining

Ein interaktives Dialogue Lab zum Üben von Gesprächsführung. Diese Anwendung ermöglicht es Führungskräften, schwierige Gespräche mit einem KI-Partner zu simulieren und anschließend Feedback von einem KI-Mentor zu erhalten.

## Projektstruktur

- `prompts/`: Enthält die detaillierten Rollenbeschreibungen für den KI-Partner und den Mentor (IT-Betrieb & Controlling).
- `scenarios/`: Hintergrundinformationen und Aufgabenstellungen für die verschiedenen Übungsszenarien.
- `index.html`: Die Benutzeroberfläche für das Training.

## Voraussetzungen

- Ein moderner Webbrowser.
- Eine entsprechende Backend-Logik (in `app.js`), um die Verbindung zur Gemini API oder einem anderen LLM herzustellen.

## Starten

Einfach die `index.html` im Browser öffnen oder über einen lokalen Webserver (z.B. Live Server in VS Code) starten.
